## 🚀 MY PROJECTS

### 1. Smart Regulator – LPG Gas Leakage Detection

**Components:**
- ESP32
- MQ-6 Gas Sensor
- MG995 Servo Motor
- Buzzer and LEDs
- Manual Reset Button

**Working:**

The MQ-6 detects LPG leakage. ESP32 processes the sensor signal and activates the servo motor to close the regulator valve when the preset threshold is exceeded. The buzzer and red LED provide an alert.
