## 🚀 Featured Engineering Projects

### 🔥 1. Smart Regulator – LPG Gas Leakage Detection System

**Project Domain:** Embedded Systems | Electronics | Safety Automation

**Project Description:**

An automatic LPG gas leakage detection and safety system designed to detect gas leakage and automatically close the regulator valve.

**Hardware Components:**

- ESP32 Microcontroller
- MQ-6 LPG Gas Sensor
- MG995 Servo Motor
- Buzzer
- Red LED and Green LED
- Manual Reset Push Button

**Working Principle:**

1. MQ-6 detects LPG leakage.
2. ESP32 processes the sensor signal.
3. When the detected level exceeds the preset threshold, the servo motor closes the regulator valve.
4. The buzzer sounds and red LED indicates gas leakage.
5. Manual reset is required after inspection.

**Technologies:** ESP32 | Embedded C | Arduino IDE | Sensor Interfacing
